# manga-e-commerce
# Fase 1: Sviluppo Strutturale (Versione Grezza)

In questa branch è contenuta la versione del sito relativa alla **Fase 1** del progetto.

### Stato del Progetto
Il sito si trova attualmente in uno stadio **grezzo** e funzionale. Gli obiettivi principali di questa fase sono stati:
* Impostazione dell'architettura software e della struttura del database.
* Implementazione delle funzionalità core (Carrello, Catalogo, ...).
* Creazione di un layout base responsive utilizzando Bootstrap.

### Prossimi Passi Fase 2
Questa versione rappresenta lo scheletro del sito ed è **ancora da raffinare nel dettaglio**. Le fasi successive si concentreranno su:
1.  **Refactoring del design**: Miglioramento dell'interfaccia utente (UI) e dell'esperienza utente (UX).
2.  **Ottimizzazione del codice**: Pulizia e raffinamento della logica PHP e JavaScript.
